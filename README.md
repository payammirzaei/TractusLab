# TractusLab

Interactive Tractus-X learning for people who should not need to read a wall of documentation before understanding a dataspace.

## MVP

The first scenario explains controlled data exchange through a simple battery Product Carbon Footprint story:

`Identity → Catalog → Policy → Contract → Transfer`

The learning principle is simple: **business problem first, technical term second**.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Railway deployment

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current scope

This first version is intentionally simulation-only. No EDC, DTR, backend, database, or AI tutor is required yet.
